# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability") or email fnmontefalcone@gmail.com with:

- affected version or commit
- reproduction steps and impact
- any proposed fix

I aim to acknowledge reports within 3 business days and to share a remediation plan within 14 days. Please allow time for a fix before public disclosure.

## Scope

This repository is the portfolio edition of Odoo Shield Warden (Odoo 18). Findings about the controls engine, evidence chain or module code are in scope. Vulnerabilities in Odoo itself should go to Odoo's own security team.
